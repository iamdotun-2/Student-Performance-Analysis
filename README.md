# Student Performance Data Analysis

A beginner-friendly data analysis project exploring patterns in student academic performance using Python.

##  Project Overview

This project analyzes student performance data to explore relationships between academic performance, study time, absences, and previous grades.

The analysis was carried out using Python, Pandas, Matplotlib, and Jupyter Notebook.

##  Questions Explored

- What does the distribution of final grades look like?
- Is study time associated with final grades?
- Do absence patterns show a clear relationship with final performance?
- How strongly is the second-period grade related to the final grade?

## 🔎 Key Findings

- The average final grade was **10.42/20**.
- The median final grade was **11/20**.
- Study-time category 3 had the highest average final grade at **11.40**.
- Absence groups did not show a clear linear relationship with final grades.
- The correlation between second-period grade (G2) and final grade (G3) was **0.9049**, indicating a very strong positive relationship.

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📁 Project Files

- `student_performance_analysis.ipynb` — analysis notebook containing the data exploration, calculations, visualizations, and findings.
- `student-mat.csv` — dataset used for the analysis.

## 📚 Dataset

The project uses the **Student Performance** dataset from the UCI Machine Learning Repository.

The dataset contains student academic, demographic, and social information.
